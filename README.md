# Anuj Sharma | Portfolio

Personal portfolio site for Anuj Sharma, Software Quality Engineer at Motorola Solutions.

Live at: https://anujsharma0307.github.io

## Stack

- Static HTML + Tailwind (via CDN) + JetBrains Mono / Inter / Space Grotesk
- Vanilla JS: typewriter hero, custom cursor, scroll-reveal via IntersectionObserver
- Hosted on GitHub Pages (user site, `main` branch root)

## Local preview

```bash
python3 -m http.server 8081
# open http://localhost:8081
```
